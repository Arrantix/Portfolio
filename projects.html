01 / PC-DASHBOARD

The idea

How can live system metrics live in one place without overwhelming the reader?

The implementation

PySide6 separates system and network views; psutil reads local metrics while slower probes run in the background. GitHub Actions builds the Windows executable and publishes a SHA-256 checksum. GPU data appears when NVIDIA telemetry is available.
